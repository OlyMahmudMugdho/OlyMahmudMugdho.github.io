# কার ফ্লিট (Car Fleet)

সমস্যার লিংক: https://leetcode.com/problems/car-fleet/

## সমস্যাটা কী?

একই লেনের রাস্তায় `target` মাইলের দিকে অনেকগুলো গাড়ি ছুটছে। প্রতিটা গাড়ির শুরুর অবস্থান (`position`) আর গতি (`speed`) দেওয়া আছে। যেহেতু রাস্তাটা এক লেনের, পেছনের কোনো গাড়ি সামনের গাড়িকে ওভারটেক করতে পারবে না—বরং ধরে ফেললে দুটো মিলে সামনের ধীর গতির গাড়িটার সমান গতিতে একসাথে চলবে (একে একটা **car fleet** বলে)। গন্তব্যে মোট কয়টা ফ্লিট পৌঁছাবে, সেটাই বের করতে হবে।

---

# সহজভাবে চিন্তা করি

এখানে মূল আইডিয়াটা হলো—গন্তব্যের **সবচেয়ে কাছের গাড়িটা থেকে** পেছনের দিকে দেখা!

কোনো গাড়ি যদি `pos` অবস্থানে থাকে আর তার গতি `spd` হয়, তাহলে ফাঁকা রাস্তায় তার গন্তব্যে পৌঁছাতে সময় লাগবে:

```text
t = (target - pos) / spd
```

এবার ভাবুন:
- পেছনের গাড়িটার পৌঁছাতে যদি সামনের ফ্লিটের চেয়ে **কম বা সমান** সময় লাগে (`t <= stack[-1]`), তার মানে সে স্পিডে বেশি, তাই গন্তব্যের আগেই সামনের গাড়িকে ধরে ফেলে ওটার সাথে মিশে যাবে!
- আর যদি **বেশি** সময় লাগে (`t > stack[-1]`), তাহলে সে কখনোই সামনের গাড়িকে ধরতে পারবে না—অর্থাৎ সে নিজেই একটা **নতুন ফ্লিট**!

# অ্যালগরিদম

১. `(position, speed)` জোড়াগুলোকে `position`-এর বড় থেকে ছোট (গন্তব্যের কাছ থেকে দূর) ক্রমে সর্ট করি।
২. একটা খালি `stack` নিই, যেখানে প্রতিটি আলাদা ফ্লিটের পৌঁছানোর সময় থাকবে।
৩. সর্ট করা প্রতিটা গাড়ির `(pos, spd)` নিয়ে:
   - `t = (target - pos) / spd` বের করি।
   - `stack` খালি থাকলে বা `t > stack[-1]` হলে `t` স্ট্যাকে পুশ করি (নতুন ফ্লিট)।
৪. শেষে `len(stack)` রিটার্ন করি।

```text
function carFleet(target, position, speed)
    cars = sorted(zip(position, speed), reverse=True)
    stack = []
    for pos, spd in cars
        t = (target - pos) / spd
        if not stack or t > stack[-1]
            stack.append(t)
    return len(stack)
```

# ধাপে ধাপে ড্রাই রান

`target = 12, position = [10, 8, 0, 5, 3], speed = [2, 4, 1, 1, 3]`

অবস্থান অনুযায়ী বড় থেকে ছোট সাজালে পাই: `[(10, 2), (8, 4), (5, 1), (3, 3), (0, 1)]`।

- `(10, 2)`: `t = (12 - 10) / 2 = 1.0` → স্ট্যাক খালি, পুশ → `[1.0]`
- `(8, 4)`: `t = (12 - 8) / 4 = 1.0` → `1.0 <= 1.0`, সামনেরটার সাথে মিশে যাবে → `[1.0]`
- `(5, 1)`: `t = (12 - 5) / 1 = 7.0` → `7.0 > 1.0`, ধরতে পারবে না! নতুন ফ্লিট → `[1.0, 7.0]`
- `(3, 3)`: `t = (12 - 3) / 3 = 3.0` → `3.0 <= 7.0`, `7.0`-এর ফ্লিটে মিশে যাবে → `[1.0, 7.0]`
- `(0, 1)`: `t = (12 - 0) / 1 = 12.0` → `12.0 > 7.0`, নতুন ফ্লিট → `[1.0, 7.0, 12.0]`

তাহলে মোট ফ্লিট = `len(stack) = 3`।

---

# কোড বিশ্লেষণ

```python
class Solution:
    def carFleet(self, target: int, position: list[int], speed: list[int]) -> int:
        cars = sorted(zip(position, speed), reverse=True)
        stack = []

        for pos, spd in cars:
            t = (target - pos) / spd

            if not stack or t > stack[-1]:
                stack.append(t)

        return len(stack)
```

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n log n)` — গাড়িগুলো সর্ট করার জন্য।
- **Space Complexity:** `O(n)` — সর্টেড লিস্ট এবং স্ট্যাকের জন্য।

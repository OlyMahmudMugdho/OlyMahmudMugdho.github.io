# ক্লাইম্বিং স্টেয়ার্স (Climbing Stairs)

সমস্যার লিংক: https://leetcode.com/problems/climbing-stairs/

## সমস্যাটা কী?

আমাদের `n` ধাপের একটা সিঁড়ি দিয়ে ওপরে উঠতে হবে। প্রতিবার আপনি হয় `1` ধাপ, না হয় `2` ধাপ উঠতে পারবেন। মোট কতভাবে চূড়ায় পৌঁছানো সম্ভব?

যেমন `n = 3` হলে `3` ভাবে ওঠা যায় (`1+1+1`, `1+2`, `2+1`)।

---

# সহজভাবে চিন্তা করি

ভাবুন তো আপনি `i`-তম সিঁড়িতে কীভাবে পৌঁছাতে পারেন?

যেহেতু একবারে `1` বা `2` ধাপের বেশি ওঠা যায় না, তাই শেষ লাফটা দিয়ে আপনি আসতে পারেন:
- `(i - 1)` নম্বর সিঁড়ি থেকে (`1` ধাপ উঠে), অথবা
- `(i - 2)` নম্বর সিঁড়ি থেকে (`2` ধাপ উঠে)।

তার মানে `i`-তম সিঁড়িতে ওঠার মোট উপায়:

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

এটা হুবহু ফিবোনাচ্চি ধারা! আগের উত্তরগুলো `dp` লিস্টে জমিয়ে রাখলেই বারবার হিসাব না করে `O(n)` সময়ে উত্তর বের হয়ে আসে।

---

# অ্যালগরিদম

1. বেস কেস দিয়ে `dp = [0, 1, 2, 3]` তৈরি করি (`n = 0, 1, 2, 3`-এর জন্য)।
2. যদি `n > 3` হয়, `i = 4` থেকে `n` পর্যন্ত লুপ চালিয়ে `dp[i - 1] + dp[i - 2]` যোগ করি।
3. শেষে `dp[n]` রিটার্ন করি।

```text
function climbStairs(n)
    dp = [0, 1, 2, 3]
    for i from 4 to n
        dp.append(dp[i - 1] + dp[i - 2])
    return dp[n]
```

---

# ধাপে ধাপে ড্রাই রান

`n = 5` ধরুন:

1. শুরুতে `dp = [0, 1, 2, 3]`।
2. `i = 4`: `dp[3] + dp[2] = 3 + 2 = 5` → `dp = [0, 1, 2, 3, 5]`।
3. `i = 5`: `dp[4] + dp[3] = 5 + 3 = 8` → `dp = [0, 1, 2, 3, 5, 8]`।

উত্তর: `dp[5] = 8`।

---

# কোড বিশ্লেষণ

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        dp = [0, 1, 2, 3]

        if n > 3:
            i = 4

            while i <= n:
                self.calculate(dp, i)
                i += 1

        return dp[n]

    def calculate(self, dp: list, n: int):
        dp.append(dp[n - 1] + dp[n - 2])
```

---

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n)` — `4` থেকে `n` পর্যন্ত একবার করেই হিসাব হয়।
- **Space Complexity:** `O(n)` — `dp` অ্যারের জন্য।

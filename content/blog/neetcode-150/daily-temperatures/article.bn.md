# ডেইলি টেম্পারেচার্স (Daily Temperatures)

সমস্যার লিংক: https://leetcode.com/problems/daily-temperatures/

## সমস্যাটা কী?

প্রতিদিনের তাপমাত্রা দিয়ে একটা অ্যারে `temperatures` বানানো আছে। আমাদের প্রতিটা দিনের জন্য বলে দিতে হবে—ওই দিনের চেয়ে গরম একটা দিন পেতে আর **কতদিন** অপেক্ষা করতে হবে। সামনে আর কোনো গরম দিন না থাকলে `0` বসাতে হবে।

যেমন `[73, 74, 75, 71, 69, 72, 76, 73]` হলে, `73`-এর পরের দিনই `74` (১ দিন অপেক্ষা), `75`-এর পর `76` পেতে ৪ দিন অপেক্ষা, আর `76`-এর পর গরম দিন না থাকায় `0`।

---

# সহজভাবে চিন্তা করি

প্রতিটা দিনের জন্য সামনের সব দিন খুঁজতে গেলে `O(n^2)` সময় লেগে যাবে। এর বদলে আমরা উল্টোভাবে ভাবি:

যে দিনগুলো এখনো গরম দিনের অপেক্ষায় বসে আছে, তাদের ইনডেক্সগুলো একটা **স্ট্যাকে** জমিয়ে রাখি। আজকের তাপমাত্রা যদি স্ট্যাকের ওপরের দিনের চেয়ে বেশি হয়, তাহলে ওই অপেক্ষমাণ দিনটার উত্তর আজই মিলে গেল (`res[j] = i - j`)!

এভাবে স্ট্যাকের ভেতর তাপমাত্রাগুলো বড় থেকে ছোট ক্রমে (monotonic decreasing) সাজানো থাকে।

---

# অ্যালগরিদম

১. খালি `stack` আর সবগুলো `0` দিয়ে `res = [0] * len(temperatures)` তৈরি করি।
২. প্রতিটা দিন `i` (`0` থেকে শেষ পর্যন্ত)-এর জন্য:
   - যতক্ষণ `stack` খালি নয় এবং `temperatures[stack[-1]] < temperatures[i]`:
     - `j = stack.pop()` করি এবং `res[j] = i - j` বসিয়ে দিই।
   - এরপর `i`-কে `stack`-এ ঢুকিয়ে দিই (এবার `i` নিজের চেয়ে গরম দিনের অপেক্ষায় থাকবে)।
৩. শেষে `res` রিটার্ন করি।

```text
function dailyTemperatures(temperatures)
    stack = deque()
    res = [0] * len(temperatures)
    for i from 0 to len(temperatures) - 1
        while stack and temperatures[stack[-1]] < temperatures[i]
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res
```

# ধাপে ধাপে ড্রাই রান

`temperatures = [73, 74, 75, 71, 69, 72, 76, 73]`

- **দিন ০ (৭৩):** স্ট্যাক খালি → `[0]`
- **দিন ১ (৭৪):** `74 > 73` → `0` পপ করে `res[0] = 1 - 0 = 1`, পুশ `1` → `[1]`
- **দিন ২ (৭৫):** `75 > 74` → `1` পপ করে `res[1] = 2 - 1 = 1`, পুশ `2` → `[2]`
- **দিন ৩ (৭১), দিন ৪ (৬৯):** ছোট বলে পপ হবে না → `[2, 3, 4]`
- **দিন ৫ (৭২):** `69` আর `71`-এর চেয়ে বড়! তাই `4` পপ (`res[4] = 1`), `3` পপ (`res[3] = 2`), পুশ `5` → `[2, 5]`
- **দিন ৬ (৭৬):** `5` পপ (`res[5] = 1`), `2` পপ (`res[2] = 4`), পুশ `6` → `[6]`
- **দিন ৭ (৭৩):** পুশ `7` → `[6, 7]` (এদের জন্য আর গরম দিন নেই, তাই `0` থাকবে)।

উত্তর: `[1, 1, 4, 2, 1, 1, 0, 0]`।

# কোড বিশ্লেষণ

```python
from collections import deque

class Solution:
    def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
        stack = deque()
        res = [0] * len(temperatures)

        i = 0

        while i < len(temperatures):
            while (len(stack) != 0) and (temperatures[stack[-1]] < temperatures[i]):
                j = stack.pop()
                res[j] = i - j

            stack.append(i)
            i += 1

        return res
```

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n)` — প্রতিটা দিন স্ট্যাকে ঠিক একবার ঢোকে আর সর্বোচ্চ একবার বের হয়।
- **Space Complexity:** `O(n)` — স্ট্যাক এবং আউটপুটের জন্য।

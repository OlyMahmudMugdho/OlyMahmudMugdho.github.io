# গ্রুপ অ্যানাগ্রামস (Group Anagrams)

সমস্যার লিংক: https://leetcode.com/problems/group-anagrams

## সমস্যাটা কী?

আমাদের কাছে অনেকগুলো শব্দের (string) একটা লিস্ট `strs` দেওয়া আছে। কাজ হলো—যে শব্দগুলো একে অপরের **অ্যানাগ্রাম (anagram)**, সেগুলোকে একই গ্রুপে আলাদা আলাদা করে সাজানো।

অ্যানাগ্রাম মানে কী? ধরুন `"eat"`, `"tea"`, আর `"ate"`—এই তিনটা শব্দের অক্ষরগুলো এলোমেলো, কিন্তু খেয়াল করলে দেখবেন প্রতিটাতেই ঠিক একটা `a`, একটা `e`, আর একটা `t` আছে। অর্থাৎ অক্ষরগুলোর সংখ্যা হুবহু এক, শুধু জায়গা বদলেছে। এগুলোই অ্যানাগ্রাম।

---

# উদাহরণ

ধরুন ইনপুট হলো:

```text
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
```

তাহলে আউটপুট আসবে:

```text
[
    ["eat", "tea", "ate"],
    ["tan", "nat"],
    ["bat"]
]
```

গ্রুপগুলো কোনটার আগে কোনটা থাকল, সেটা নিয়ে কোনো বাধ্যবাধকতা নেই।

---

# সহজভাবে চিন্তা করি

প্রথমেই মাথায় আসে—প্রতিটা শব্দকে যদি অক্ষর অনুযায়ী সর্ট (sort) করে ফেলি, তাহলে কেমন হয়? যেমন:

```text
"eat" -> "aet"
"tea" -> "aet"
"ate" -> "aet"
```

তিনটাই `"aet"` হয়ে যাচ্ছে, তাই সহজেই এক গ্রুপে ফেলা যায়। কিন্তু প্রতিটা শব্দ সর্ট করতে `O(k log k)` সময় লাগে। শব্দগুলো বড় হলে এটা একটু ধীরগতির হয়ে যায়।

এর চেয়ে অনেক স্মার্ট একটা উপায় আছে। ইংরেজি ছোট হাতের অক্ষর তো মাত্র `26`টা (`a` থেকে `z`)। আমরা যদি প্রতিটা শব্দের জন্য `26` ঘরের একটা অ্যারে নিয়ে গুনে ফেলি কোন অক্ষর কতবার আছে, তাহলেই তো ওই শব্দের একটা ইউনিক পরিচয় বা "সিগনেচার" তৈরি হয়ে যায়!

দুটো শব্দ অ্যানাগ্রাম হলে তাদের এই `26` ঘরের অ্যারেটাও হুবহু এক হবে। ব্যাস, সেটাই হবে আমাদের হ্যাশ ম্যাপের key!

*(ছোট্ট একটা টেকনিক্যাল ব্যাপার: Python-এ লিস্ট বা অ্যারে মিউটেবল বলে সরাসরি ডিকশনারির key করা যায় না। তাই `str(key_arr)` দিয়ে সেটাকে স্ট্রিং বানিয়ে key হিসেবে ব্যবহার করব।)*

# অ্যালগরিদম

১. প্রথমে একটা খালি হ্যাশ ম্যাপ `hmap = {}` নিই।
২. `strs`-এর প্রতিটা শব্দ `s`-এর জন্য:
   - `26`টা শূন্য নিয়ে `key_arr = [0] * 26` বানাই।
   - শব্দের প্রতিটা অক্ষরের ইনডেক্স বের করি `ord(letter.lower()) - 97` দিয়ে (`a` মানে `0`, `b` মানে `1`... `z` মানে `25`), আর সেই ঘরের মান `1` বাড়াই।
   - `key = str(key_arr)` দিয়ে হ্যাশেবল key বানাই।
   - এই `key` আগে থেকেই `hmap`-এ থাকলে ওই লিস্টে `s` যোগ করি, না থাকলে নতুন একটা লিস্ট `[s]` তৈরি করি।
৩. সবশেষে `hmap`-এর সব গ্রুপ (values) রিটার্ন করে দিই।

```text
function groupAnagrams(strs)
    hmap = {}
    for s in strs
        key_arr = [0] * 26
        for letter in s
            order = ord(lower(letter)) - 97
            key_arr[order] += 1
        key = str(key_arr)
        if key in hmap: hmap[key].append(s)
        else: hmap[key] = [s]
    return list(hmap.values())
```

# ধাপে ধাপে ড্রাই রান

`strs = ["eat", "tea", "tan", "ate", "nat", "bat"]` নিয়ে দেখি:

১. **"eat"**: `a->1, e->1, t->1`। ম্যাপে নেই, তাই নতুন গ্রুপ তৈরি হলো → `["eat"]`
২. **"tea"**: `a->1, e->1, t->1`। সিগনেচার `"eat"`-এর সাথে মিলে গেছে! তাই ওই গ্রুপেই ঢুকল → `["eat", "tea"]`
৩. **"tan"**: `a->1, n->1, t->1`। নতুন সিগনেচার → `["tan"]`
৪. **"ate"**: `a->1, e->1, t->1`। আবার প্রথম গ্রুপে → `["eat", "tea", "ate"]`
৫. **"nat"**: `a->1, n->1, t->1`। `"tan"`-এর গ্রুপে → `["tan", "nat"]`
৬. **"bat"**: `a->1, b->1, t->1`। একদম নতুন → `["bat"]`

শেষে সব ভ্যালু একসাথে রিটার্ন করলেই উত্তর চলে আসে।

# কোড বিশ্লেষণ

```python
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hmap = {}

        for s in strs:
            key_arr = [0] * 26

            for letter in s:
                order = ord(letter.lower()) - 97
                key_arr[order] = key_arr[order] + 1

            key = str(key_arr)

            if hmap.get(key):
                hmap[key].append(s)
            else:
                hmap[key] = [s]

        return [val for val in hmap.values()]
```

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n * k)` — যেখানে `n` হলো মোট শব্দের সংখ্যা আর `k` হলো প্রতিটি শব্দের গড় দৈর্ঘ্য। সর্ট না করায় `log k` ফ্যাক্টরটা বেঁচে গেল।
- **Space Complexity:** `O(n * k)` — সবগুলো শব্দ হ্যাশ ম্যাপে জমা রাখার জন্য।

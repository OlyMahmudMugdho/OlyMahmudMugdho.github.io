# মিন কস্ট ক্লাইম্বিং স্টেয়ার্স (Min Cost Climbing Stairs)

সমস্যার লিংক: https://leetcode.com/problems/min-cost-climbing-stairs/

## সমস্যাটা কী?

প্রতিটা সিঁড়িতে পা রাখার একটা খরচ (`cost[i]`) দেওয়া আছে। খরচটা দিলে আপনি সেখান থেকে `1` বা `2` ধাপ ওপরে উঠতে পারবেন। আপনি শুরু করতে পারেন ইনডেক্স `0` অথবা `1` থেকে। সিঁড়ির একদম ওপরে (`len(cost)` অবস্থানে) পৌঁছাতে **সর্বনিম্ন মোট খরচ** কত হবে?

যেমন `cost = [10, 15, 20]` হলে, `1` নম্বর সিঁড়ি থেকে শুরু করে `15` দিয়ে `2` ধাপ লাফ দিলেই ওপরে চলে যাওয়া যায়—তাই সর্বনিম্ন খরচ `15`।

---

# সহজভাবে চিন্তা করি

`i`-তম অবস্থানে পৌঁছাতে হলে আপনাকে আসতে হবে:
- `i - 1` থেকে (`dp[i - 1] + cost[i - 1]` খরচে), অথবা
- `i - 2` থেকে (`dp[i - 2] + cost[i - 2]` খরচে)।

স্বাভাবিকভাবেই আমরা এই দুটোর মধ্যে যেটা **ছোট**, সেটাই বেছে নেব!

আর মজার ব্যাপার হলো—প্রতিটা ধাপে যেহেতু শুধু আগের **দুটো** মান (`a` আর `b`) লাগে, তাই পুরো `dp` অ্যারে বানানোর কোনো দরকারই নেই। মাত্র দুটো ভেরিয়েবল দিয়েই `O(1)` স্পেসে কাজ হয়ে যায়! যেহেতু `0` আর `1` নম্বর সিঁড়িতে দাঁড়ানো ফ্রি, তাই শুরুতে `a = 0, b = 0`।

---

# অ্যালগরিদম

1. `a = 0` ও `b = 0` নিই।
2. `i = 2` থেকে `len(cost)` পর্যন্ত লুপ চালাই:
   - নতুন খরচ = `min(b + cost[i - 1], a + cost[i - 2])`।
   - `a, b = b, নতুন খরচ` করে ভেরিয়েবল দুটো এক ঘর সামনে সরাই।
3. শেষে `b` রিটার্ন করি।

```text
function minCostClimbingStairs(cost)
    a = 0, b = 0
    for i from 2 to len(cost)
        a, b = b, min(b + cost[i - 1], a + cost[i - 2])
    return b
```

---

# ধাপে ধাপে ড্রাই রান

`cost = [10, 15, 20]`, শুরুতে `a = 0, b = 0`:

1. `i = 2`: `min(0 + 15, 0 + 10) = 10` → `a = 0, b = 10`।
2. `i = 3` (চূড়া): `min(10 + 20, 0 + 15) = 15` → `a = 10, b = 15`।

চূড়ান্ত উত্তর: `b = 15`।

---

# কোড বিশ্লেষণ

```python
class Solution:
    def minCostClimbingStairs(self, cost: list[int]) -> int:
        a, b = 0, 0

        for i in range(2, len(cost) + 1):
            a, b = b, min(
                b + cost[i - 1],
                a + cost[i - 2]
            )

        return b
```

---

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n)` — পুরো `cost` অ্যারে একবার লুপ ঘোরে।
- **Space Complexity:** `O(1)` — মাত্র দুটো ভেরিয়েবল `a` ও `b` লাগে।

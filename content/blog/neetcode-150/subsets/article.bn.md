# Subsets

সমস্যার লিংক: https://leetcode.com/problems/subsets/

## সমস্যাটা কী?

একটি অ্যারে `nums` দেওয়া আছে, যেখানে সবগুলো সংখ্যা আলাদা (unique)। আমাদের এই অ্যারের **সব সম্ভাব্য সাবসেট** (power set) বের করে রিটার্ন করতে হবে।

যেমন `nums = [1, 2, 3]` হলে মোট `8`টা সাবসেট হবে: `[[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]`।

---

# সহজভাবে চিন্তা করি

প্রতিটা সংখ্যা `nums[i]`-এর জন্য আমাদের হাতে ঠিক **দুটো সিদ্ধান্ত** থাকে:
1. সংখ্যাটা বর্তমান সাবসেটে **নেব** (`path.append(nums[i])`)।
2. সংখ্যাটা **নেব না** (`path.pop()`)।

যখন `i` অ্যারের শেষ মাথায় পৌঁছে যাবে (`i >= len(nums)`), তখন প্রতিটা সংখ্যার ব্যাপারে সিদ্ধান্ত নেওয়া শেষ! তাই তখন `path.copy()` করে `result`-এ জমা করে দেব।

---

# ডিসিশন ট্রি (Decision Tree)

`nums = [1, 2, 3]`-এর জন্য প্রতি ধাপে **নেব** (বাম) অথবা **বাদ দেব** (ডান) সিদ্ধান্তগুলো নিচের মতো একটা ট্রি তৈরি করে:

```tree
[]
  [1] | +1
    [1,2] | +2
      [1,2,3] !hit
      [1,2] !hit
    [1] | 2 বাদ
      [1,3] !hit
      [1] !hit
  [] | 1 বাদ
    [2] | +2
      [2,3] !hit
      [2] !hit
    [] | 2 বাদ
      [3] !hit
      [] !hit
```

একদম নিচের প্রতিটি পাতাই (leaf) একটি আলাদা সাবসেট!

---

# অ্যালগরিদম

1. `result = []` এবং `path = []` নিই।
2. `dfs(i)` ফাংশনে:
   - `i >= len(nums)` হলে `result.append(path.copy())` করে `return` করি।
   - `nums[i]` যোগ করে `dfs(i + 1)` কল দিই (নেওয়ার রাস্তা)।
   - `path.pop()` করে `dfs(i + 1)` কল দিই (বাদ দেওয়ার রাস্তা)।
3. `dfs(0)` চালিয়ে `result` রিটার্ন করি।

```text
function subsets(nums)
    result = []
    path = []

    function dfs(i)
        if i >= len(nums):
            result.append(path.copy())
            return
        path.append(nums[i])
        dfs(i + 1)
        path.pop()
        dfs(i + 1)

    dfs(0)
    return result
```

---

# ধাপে ধাপে ড্রাই রান

`nums = [1, 2]` ধরুন:

1. `dfs(0)`:
   - `1` নিলাম → `path = [1]`, `dfs(1)`:
     - `2` নিলাম → `path = [1, 2]`, `dfs(2)` → `[1, 2]` সেভ।
     - `2` বাদ → `path = [1]`, `dfs(2)` → `[1]` সেভ।
   - `1` বাদ → `path = []`, `dfs(1)`:
     - `2` নিলাম → `path = [2]`, `dfs(2)` → `[2]` সেভ।
     - `2` বাদ → `path = []`, `dfs(2)` → `[]` সেভ।

উত্তর: `[[1, 2], [1], [2], []]`।

---

# কোড বিশ্লেষণ

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        result = []
        path = []

        def dfs(i: int):
            if i >= len(nums):
                result.append(path.copy())
                return

            path.append(nums[i])
            dfs(i + 1)

            path.pop()
            dfs(i + 1)

        dfs(0)
        return result
```

*(খেয়াল রাখবেন: `path.copy()` না দিলে একই লিস্টের রেফারেন্স সেভ হবে, আর শেষে সবগুলো ফাঁকা লিস্ট `[]` হয়ে যাবে!)*

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n * 2^n)` — মোট `2^n`টি সাবসেট এবং প্রতিটা কপি করতে `O(n)` সময়।
- **Space Complexity:** `O(n)` রিকার্শন স্ট্যাক ও `path`-এর জন্য (আউটপুট ধরলে `O(n * 2^n)`)।

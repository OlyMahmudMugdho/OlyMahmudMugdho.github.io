# ভ্যালিড প্যারেন্থেসিস (Valid Parentheses)

সমস্যার লিংক: https://leetcode.com/problems/valid-parentheses/

## সমস্যাটা কী?

`'('`, `')'`, `'{'`, `'}'`, `'['`, `']'`—এই ব্র্যাকেটগুলো দিয়ে একটা স্ট্রিং `s` দেওয়া আছে। দেখতে হবে ব্র্যাকেটগুলো ঠিকঠাক নিয়ম মেনে খোলা ও বন্ধ হয়েছে কি না।

যেমন `"()[]{}"` একদম ঠিক আছে (`true`), কিন্তু `"([)]"` ভুল (`false`)—কারণ `(` বন্ধ হওয়ার আগেই `[` বন্ধ করার চেষ্টা করা হয়েছে!

---

# সহজভাবে চিন্তা করি

যখনই আপনি কোনো **ক্লোজিং** ব্র্যাকেট (যেমন `]`) দেখবেন, সেটার সাথে মিলতে হবে **একদম শেষে যে ব্র্যাকেটটা খোলা হয়েছিল** তার! মানে যেটা সবার শেষে এসেছে, সেটা সবার আগে বন্ধ হবে (Last-In, First-Out)।

আর কম্পিউটার সায়েন্সে LIFO মানেই হলো **স্ট্যাক (Stack)**!

আমরা একটা ছোট্ট ডিকশনারি `pdict` রাখব যাতে সহজেই বলে দেওয়া যায় কোন ক্লোজিং ব্র্যাকেটের বিপরীতে কোন ওপেনিং ব্র্যাকেট দরকার।

---

# অ্যালগরিদম

1. একটা খালি `stack` আর ম্যাপ `pdict = {')': '(', '}': '{', ']': '['}` তৈরি করি।
2. স্ট্রিংয়ের প্রতিটা অক্ষর `p`-এর জন্য:
   - ওপেনিং ব্র্যাকেট (`(`, `{`, `[`) হলে সোজা `stack`-এ ঢুকিয়ে দিই।
   - ক্লোজিং ব্র্যাকেট হলে দেখি `stack` খালি না থাকা অবস্থায় `stack[-1]` কি `pdict[p]`-এর সমান কি না। সমান হলে স্ট্যাক থেকে ওটা পপ করি (মানে জোড়া মিলে গেছে!)। না মিললে `p` স্ট্যাকে রেখে দিই (অথবা সরাসরি `False` রিটার্ন করলেও চলে)।
3. লুপ শেষে স্ট্যাক যদি পুরোপুরি খালি হয় (`len(stack) == 0`), তাহলে `True`, নাহলে `False`।

```text
function isValid(s)
    stack = deque()
    pdict = {')': '(', '}': '{', ']': '['}
    for p in s
        if p in ('(', '{', '[')
            stack.append(p)
        else
            if len(stack) > 0 and stack[-1] == pdict[p]
                stack.pop()
            else
                stack.append(p)
    return len(stack) == 0
```

# ধাপে ধাপে ড্রাই রান

`s = "({[]})"`

1. `'('` → ওপেনিং → স্ট্যাক: `['(']`
2. `'{'` → ওপেনিং → স্ট্যাক: `['(', '{']`
3. `'['` → ওপেনিং → স্ট্যাক: `['(', '{', '[']`
4. `']'` → স্ট্যাকের মাথায় `'['` আছে, মিলে গেল! পপ → `['(', '{']`
5. `'}'` → মাথায় `'{'` আছে, মিলে গেল! পপ → `['(']`
6. `')'` → মাথায় `'('` আছে, মিলে গেল! পপ → `[]`

স্ট্যাক একদম খালি, তাই উত্তর `True`।

# কোড বিশ্লেষণ

```python
from collections import deque

class Solution:
    def isValid(self, s: str) -> bool:
        stack = deque()
        pdict = {
            ')': '(',
            '}': '{',
            ']': '['
        }

        for p in s:
            if p == '(' or p == '{' or p == '[':
                stack.append(p)
            else:
                if len(stack) > 0 and stack[-1] == pdict[p]:
                    stack.pop()
                else:
                    stack.append(p)

        return len(stack) == 0
```

*(একটা ছোট্ট টিপস: `else` ব্লকে না মিললে `stack.append(p)` না করে সরাসরি `return False` করলেও কাজ হবে, আর বাকি স্ট্রিংটা লুপ ঘুরতেও হবে না!)*

# টাইম ও স্পেস কমপ্লেক্সিটি

- **Time Complexity:** `O(n)` — প্রতিটা অক্ষর একবারই চেক হয়।
- **Space Complexity:** `O(n)` — সবগুলো ওপেনিং ব্র্যাকেট হলে স্ট্যাকে `n`টা অক্ষর থাকতে পারে।
